# SEO Master

Objectif : du trafic **gratuit et récurrent**. Le SEO complète les Ads : il baisse le CAC moyen sur le long terme.

## Recherche de mots-clés (intention d'achat)
- Cibler l'intention **transactionnelle** ("acheter X", "X pas cher", "meilleur X") avant l'informationnelle.
- Structure : mot-clé principal par collection, longue traîne par produit.
- Prioriser : volume raisonnable + concurrence atteignable (longue traîne pour démarrer).

## Architecture (silo)
```
Accueil
 └─ Collection (mot-clé principal)   ← page à fort potentiel SEO
     └─ Produit (longue traîne)
     └─ Article de blog (informationnel → maille vers la collection)
```
Profondeur max 3 clics. URLs courtes, lisibles, avec le mot-clé.

## On-page (checklist par page)
- **Title tag** : mot-clé principal en début, < 60 caractères, marque à la fin.
- **Meta description** : bénéfice + CTA, ~150 caractères (impacte le CTR SERP).
- **H1 unique** contenant le mot-clé ; H2/H3 structurés.
- **Alt text** des images descriptif (SEO images + accessibilité).
- **Texte de collection** : 100–300 mots utiles en haut ou bas de page.
- **Maillage interne** : lier collections ↔ produits ↔ articles.
- **Données structurées** : schema Product (prix, avis, disponibilité) pour les rich snippets.

## Technique
Vitesse (voir `ux-ui-audit`), mobile-first, pas de contenu dupliqué (canonical sur variantes/filtres), sitemap propre.

## Livrable type
`Mot-clé cible → Title → Meta → H1 → plan de contenu → liens internes`.

## KPI suivis
Trafic organique, positions moyennes, CTR SERP, part des ventes issues de l'organique.
