# Copywriting Elite

Principe : on ne vend pas un produit, on vend une **transformation** (avant → après). Bénéfices d'abord, caractéristiques ensuite.

## Frameworks
- **AIDA** — Attention → Intérêt → Désir → Action. Fiches produits, landing pages.
- **PAS** — Problème → Agitation → Solution. Ads, emails à froid.
- **FAB** — Feature → Advantage → Benefit. Bullet points produit.
- **4U (accroches)** — Utile, Urgent, Unique, Ultra-spécifique.

## Fiche produit (structure)
1. **Titre bénéfice** (pas le nom seul) + mot-clé SEO (voir `seo-master`).
2. **Accroche** : le problème que ça règle, en 1 phrase.
3. **3–5 bullets FAB** : caractéristique → ce que ça change concrètement.
4. **Bloc réassurance** : livraison, retours, garantie.
5. **CTA** orienté action + micro-copy anti-risque ("Satisfait ou remboursé 30 j").

## Scripts Ads (hook = 3 premières secondes)
- Ouvrir sur le problème ou un résultat visuel choc (pattern interrupt).
- 1 idée = 1 vidéo. Angle unique (douleur, désir, curiosité, preuve).
- Toujours finir par un CTA clair + offre.
- Décliner 3–5 hooks par produit pour tester (créative testing).

## Email / SMS
Séquences clés : Bienvenue (bon de réduction), Abandon de panier (3 emails), Post-achat (upsell + avis), Win-back.
Objet email : bénéfice + curiosité, < 45 caractères.

## Règles
Français naturel, phrases courtes, "tu/vous" cohérent avec la marque. Zéro promesse mensongère.
Adapter le ton à la niche (voir `research/`).

## KPI suivis
CTR des Ads, taux d'ouverture / de clic email, CVR de la fiche produit, AOV (via upsells dans le copy).
