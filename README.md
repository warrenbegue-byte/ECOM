# E-COM — WARREN

Projet de création, d'optimisation et de mise à l'échelle de boutiques e-commerce hautement rentables et automatisées.

> **Rôle de l'IA** : Architecte E-commerce (Conversion, Copywriting, SEO, UI/UX, Logistique, Branding).
> Outillage réel connecté : **Shopify** (serveur MCP) — création de produits/collections, codes promo, aperçus de boutique, analytics.

---

## 🧰 Skills (compétences persistantes)

Les compétences ci-dessous sont de **vrais skills Claude Code** stockés dans `.claude/skills/`.
Elles se chargent automatiquement à chaque session et sont versionnées avec le projet.

| Skill | Rôle | Dossier |
|-------|------|---------|
| **UX/UI Audit (CRO)** | Repérer les points de friction, maximiser le taux de conversion | `.claude/skills/ux-ui-audit/` |
| **Copywriting Elite** | Fiches produits, scripts Ads (TikTok/FB), emails — frameworks AIDA/PAS | `.claude/skills/copywriting-elite/` |
| **Market Research** | Niches rentables, analyse concurrence, winning products | `.claude/skills/market-research/` |
| **SEO Master** | SEO technique, mots-clés e-com, structure des collections | `.claude/skills/seo-master/` |
| **Offer Crafting** | Bundles, upsells, cross-sells pour booster l'AOV | `.claude/skills/offer-crafting/` |

### Protocole d'auto-génération
Si une tâche exige une expertise non listée (logistique, automatisation Make/Zapier, SAV…),
un nouveau skill est créé à la volée dans `.claude/skills/<nom>/SKILL.md` et annoncé.

## 🗂️ Arborescence

```
ECOM/
├── .claude/skills/     # Les 5 skills e-commerce (persistants)
├── stores/             # Une boutique = un sous-dossier (config, thème, produits)
├── research/           # Études de niche, analyses concurrence, winning products
├── copy/               # Fiches produits, scripts Ads, séquences email
├── seo/                # Recherche de mots-clés, structure collections, briefs
└── offers/             # Bundles, upsells, cross-sells, matrices d'offres
```

## 📈 Structure de réponse standard

Chaque livrable suit ce format :
- **🧠 Analyse Stratégique** — ce qu'il faut comprendre avant d'agir
- **🚀 Plan d'Action** — étapes concrètes
- **🛠️ Livrable Clé en Main** — texte / code / structure prêt à l'emploi
- **📈 Métrique d'Impact** — KPI visé (Taux de conversion, AOV, CTR, trafic organique)
